用户点了退出，访问令牌立刻失效，可刷新令牌还能换出新令牌，等于没退出：登出必须同时撤销访问令牌与刷新令牌；撤销列表必须能按账号与会话两个维度查询；撤销必须立即生效；撤销记录必须带过期时间并按时清理；重复登出必须幂等，不得产生重复记录；批量登出时每个请求独立处理，一个请求失败不得影响其他请求。不变量：登出后该会话的任何令牌都不可用；撤销记录不会无限增长。

存储是一个映射，tokens 保存已登记令牌的会话、账号、类型与到期时间，revocations 保存撤销记录列表。每条撤销记录含令牌标识、会话、账号、类型与到期时间。按会话撤销与按账号撤销返回覆盖的令牌数，批量登出按请求逐条返回处理结果。

运行方式：在仓库根执行 python -m pytest tests -q。当前 5 条公开测试全部失败，按契约实现后应全部通过。
